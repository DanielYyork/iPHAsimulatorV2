PHA MELT SYSTEMS================This directory contains polymer melt systems generated from one or more builtPHA polymers.A melt may contain a single polymer chemistry or multiple chemistries forcopolymer and blend simulations.SYSTEM NAMING-------------Polymer melts use the naming convention    {number}_{polymer_name}_meltExamples    25_P3HB_10_meltor    25_P3HB_10_25_P4HB_10_meltwhere    25 = Number of polymer chains    P3HB_10 = Polymer speciesDIRECTORY STRUCTURE-------------------Each melt contains two subdirectories.    25_P3HB_10_melt/        inputs/            Files used to generate the melt system.            Examples include Packmol inputs and converted topology files.        simulations/            Individual simulation runs.The root directory contains the final coordinates and topology describing thepolymer melt.SIMULATION RUNS---------------Each simulation should be stored in its own subdirectory.Examples    Test_01/    Tg_01/    Anneal_01/This keeps different simulation protocols completely independent while sharingthe same parent melt system.
