# Centre an enzyme–PHA production trajectory on the PROTEIN ONLY
#
# Run from this analysis folder:
#   bash process_trajectory.sh
# Check the plan without creating any files or processing trajectories:
#   bash process_trajectory.sh --dry-run
#
# This is the only settings file used by process_trajectory.sh. No YAML needed.
# Edit values after = and save. Use plain values without quotes, spaces
# around =, or inline comments. Paths are relative to this analysis folder.
#
# Keep raw XTC, production TPR, GRO, and original index in the parent folder.
# The script generates protein_center.ndx here from the production TPR on
# its first run; it reuses that index later. Do not copy a generated index

# Protein = enzyme only (excludes LIG); System = all atoms including LIG,
# water, and ions. The original ../index.ndx is not modified or used.
#
# 1. Read the combined XTC from the parent folder.
# 2. Apply -pbc mol -ur compact -center with Protein as the centring group.
#    Save ALL frames to processed_protein_centered.xtc in this folder.

#    processed_protein_centered_every100.xtc for VMD.

#
# Old processed.xtc / processed_every100.xtc are left untouched.
# Existing new outputs are protected: rename them or change PROCESSED and
